# ADR 0002: 设备地理位置双模式定位与 WGS-84 坐标系规范

## 状态
已接受 (Accepted)

## 上下文
系统核心需求包含设备地图与设备实际物理部署位置的管理。定位模式包含：
1. 用户输入地址并通过地理编码服务搜索候选结果并选定；
2. 用户在地图上点击放置标记或拖拽标记微调（manual_pin）；
3. Excel 导入坐标或仅导入地址等待后续补齐；
4. 部分设备暂不提供位置信息（未定位设备）。

此外，全球通用地理坐标（GPS、OpenStreetMap）为 WGS-84 坐标系，而国内部分地图（高德等）返回 GCJ-02（火星坐标系），百度地图使用 BD-09。若直接混用会导致数百米至千米的视觉漂移。

## 决策
1. **数据存储基准**：数据库中存储的标准坐标统一为 **WGS-84**。
2. **字段定义**：设备表包含 `latitude`, `longitude`, `location_address`, `formatted_address`, `location_method`, `location_status`, `location_accuracy`, `location_provider`, `location_updated_at`, `location_note`。
3. **一致性约束**：
   - 经度与纬度必须严格满足：两者同时为空，或两者同时具有合法有效值（`lat ∈ [-90, 90]`, `lng ∈ [-180, 180]`）。
   - 定位状态 `location_status` 仅支持 `located`（有坐标）与 `unlocated`（无坐标）。
4. **双模式联动与来源标记**：
   - 搜索地址后直接确认为 `address_search`。
   - 搜索后拖拽标记或直接在地图点击选点为 `manual_pin`。
   - Excel 导入经纬度为 `import_coordinates`，仅导入地址为 `import_address`。
5. **坐标转换服务**：后端内置纯数学算法模块，提供 WGS-84 与 GCJ-02 / BD-09 之间的精确双向转换，对外提供标准化坐标。
6. **未定位设备保护**：未定位设备不生成假坐标标记，但正常参与监控、统计、报表导出与管理，并在地图面板中提供未定位设备专用统计抽屉与快速选点入口。

## 后果
- 保证坐标数据的一致性与严谨性，杜绝地图显示错位与脏数据。
- 保证无坐标设备在系统中的一等公民地位，不会因缺坐标而受损。
