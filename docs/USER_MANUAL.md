# IPMonitor Web 用户操作手册

本文档提供 **IPMonitor Web** 系统的各功能模块操作指南。

---

## 0. 架构体系：双门户工作模式

IPMonitor Web 采用**“态势感知驾驶舱”与“专业运维控制台”完全解耦的清晰双门户架构**：

```text
┌──────────────────────────────────────────────┐
│  监控驾驶舱 (Cockpit)                          │
│  - 沉浸式 NOC 态势大屏 / 电视墙常驻              │
│  - 全网健康度 / SLA / 设备 Top 10 时延遥测    │
│  - 全屏 GIS 空间地图 / 设备状态矩阵自由切换     │
│  - 未结告警播报墙与分组健康度进度条            │
│  - [右上角一键进入] 运维管理后台 ──────────┐   │
└────────────────────────────────────────────┼─┘
                                             │
                       ┌─────────────────────┴─┐
                       ▼                       │
┌──────────────────────────────────────────────┐
│  运维管理后台 (Admin Console)                 │
│  - 设备清单、台账编辑与状态管理               │
│  - 空间地图双模式标注与微调                   │
│  - 分组架构与网络探测配置                     │
│  - 告警规则、风暴抑制与机器人通道设置         │
│  - MTTR 可用度统计与多工作表 Excel 导出       │
│  - 官方标准 3-Sheet Excel 模板导入预检        │
│  - SQLite 数据库在线热备份与安全审计          │
│  - [左侧导航一键返回] 监控驾驶舱 ─────────────┘
└──────────────────────────────────────────────┘
```

- **访客 / 机房大屏模式**：直接访问系统默认呈现监控驾驶舱，无需繁琐登录即可监视设备连通性；
- **管理员运维模式**：点击驾驶舱右上角“运维管理后台”，输入管理员凭据即可进入后台进行设备维护、导入导出及系统设置；后台侧边栏置顶“返回监控驾驶舱”按钮，随时实现态势查看与后台运维的自由穿梭。

## 1. 监控总览大屏

- **汇总统计卡片**：
  - **受控设备总数**：当前纳入系统的资产总规模。
  - **正常在线 (绿色)**：最近一次探测成功且运行正常的设备。
  - **离线异常 (红色)**：连续失败次数达到配置阈值（默认 3 次）正式确认离线的设备。
  - **探测中/未知 (黄色)**：新录入尚未完成探测周期或正在丢包重试中的设备。
  - **整体可用度 (%)**：在线设备占比；禁用设备自动排除在分母之外。
  - **未结活动告警**：当前仍处于离线故障状态、未被恢复或未被手动标记解决的告警总数。
- **状态筛选与卡片联动**：
  - 单击卡片或顶部状态标签（如“🔴 离线”），下方设备卡片列表将自动联动过滤出对应状态的设备。
- **实时事件时间线**：
  - 右侧栏实时展示节点最新状态跃迁流水（上线、确认离线、恢复持续时长）。

## 2. 设备管理与双模式地理定位

### 2.1 新增/编辑设备
1. 进入“设备台账”，点击“新增设备”；
2. 填入设备名称、IP 地址、选择设备类型（服务器、路由器、交换机、NAS等）、所属分组；
3. 选择探测协议：
   - `ICMP Ping`：通用连通性检测；
   - `TCP 端口`：针对特定开放端口（如 NAS 445、Web 80/443 等）检测；
   - `ARP 探针`：局域网二层物理地址检测；
4. 配置探针高级参数：单次超时秒数、轮询执行周期、连续重试次数。

### 2.2 双模式地理位置选点 (核心特性)
点击表单中的“在地图上选点定位”呼出定位弹窗：
- **模式 A (地址检索定位)**：
  - 在上方输入框输入真实物理地址（如“北京市海淀区中关村大街1号”），点击“搜索”；
  - 在下拉候选项中点击目标地点，地图将平滑飞行到目标点并放置图钉；
  - 确认无误后点击“确认使用该位置”，定位方式将自动标记为 `address_search`。
- **模式 B (地图手动选点与微调)**：
  - 用户可直接在地图任意位置单击放置标记，或按住标记拖拽进行米级微调；
  - 拖拽松开后系统即时回显精准经纬度，并自动通过逆地理编码反查地址描述；
  - 确认后保存，定位方式将自动标记为 `manual_pin`。
- **清空位置**：
  - 若设备需转为纯拓扑管理，可点击“清空选点”恢复未定位状态。

## 3. Excel 台账批量导入与导出

### 3.1 官方标准模板规范
- 点击“下载Excel模板”，系统将提供包含 **3 个工作表** 的标准导入文件：
  1. `设备导入`：首行冻结并包含数据验证下拉菜单（协议、类型、坐标系等），附带标注清楚的示例行；
  2. `填写说明`：各列字段详细必填性与范围约束；
  3. `数据字典`：代码值与业务定义。

### 3.2 预检机制与防覆盖保护
1. 点击“导入台账”，选择编辑好的 `.xlsx` 文件；
2. 系统**先执行严格预检**，不向数据库写入任何数据：
   - 自动检测 IP 格式合法性、必填字段、TCP 端口数值区间、经纬度一致性（经度和纬度必须同时填写或同时为空）；
   - 校验坐标系与经纬度范围（[-90, 90], [-180, 180]）；
3. 若存在错误，错误列表将明确列出**行号、字段名称与具体错误原因**；
4. 预检全部通过后，选择执行模式：
   - `IP 重复时覆盖更新`：更新已有设备基本配置。**系统具有坐标安全保护：空白坐标默认不会覆盖数据库中已有位置**；
   - `IP 重复时跳过`：仅新增不重复的设备。

## 4. 告警中心与多渠道群机器人联动

### 4.1 告警闭环与风暴抑制
- 当设备连续失败达到重试阈值（默认 3 次），系统触发离线告警；
- **告警风暴抑制**：大批量设备同时断网时，系统在 0.5s 窗口期内自动批次合并最多 20 条事件，汇聚为单条集中告警推送，杜绝刷屏；
- 当设备恢复连通时，系统自动生成恢复事件并记录总计离线时长，向通知渠道推送恢复喜报。

### 4.2 通知渠道配置与连通性自检
进入“告警中心” -> “通知渠道与机器人设置”：
1. **企业微信 / 钉钉 / 飞书 群机器人**：
   - 开启 Webhook，选择平台并填入群机器人的 Webhook URL；
   - 点击“发送 Webhook 测试消息”，系统将真实调用接口并反馈连通性结果。
2. **SMTP 邮件通知**：
   - 填写发件服务器地址、端口（如 QQ 邮箱 smtp.qq.com:465 SSL）、发件人与授权码、收件人；
   - 支持设置**免打扰时段**（如 22:00 至次日 08:00），夜间不打扰运维人员；
   - 点击“发送测试邮件”验证邮箱凭据。

## 5. 报表中心与运维统计

- **关键指标分析**：
  - 统计周期（7天/14天/30天）内故障离线总次数；
  - **平均故障恢复时长 (MTTR)**：度量系统故障平均修复效率；
  - 故障频次 Top 5 节点排行。
- **可用度明细与报表下载**：
  - 点击“导出统计报表 (Excel)”，系统动态生成多工作表运维台账（包含可用度统计、事件明细与告警历史），满足日常汇报与留存需求。
